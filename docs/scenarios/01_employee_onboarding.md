# 01. إدارة بيانات الموظفين (Employee Onboarding)

## 📌 الهدف
إضافة السائقين والموظفين الجدد إلى النظام وتتبع بياناتهم الأساسية ومستنداتهم لضمان عدم انتهاء صلاحيتها.

## 📝 السيناريو التشغيلي
1. تم تعيين سائق جديد.
2. يدخل مدير الموارد البشرية إلى النظام ويضيف بياناته الأساسية (الاسم، الهاتف، الرقم المدني).
3. **نقطة مهمة:** يتم تحديد "الراتب الرسمي" (حسب العقد الحكومي) و "الراتب الفعلي" (المتفق عليه داخلياً).
4. يذهب المدير إلى تبويب "المستندات" في ملف الموظف.
5. يقوم برفع صورة رخصة القيادة، جواز السفر، والبطاقة المدنية.
6. يتم تحديد "تاريخ الانتهاء" لكل مستند.
7. سيقوم النظام بتنبيه الإدارة (عبر لوحة التحكم أو إشعارات لاحقاً) قبل انتهاء أي مستند لتجديده وتجنب الغرامات القانونية.
