## 💥 13. المخرجات المحاسبية — محرك الرواتب (إقفال مايو 2026)

### الصيغة:
```
الإجمالي قبل الخصم = الراتب الفعلي + بونص الطلبات + بدل الوقود
إجمالي الخصومات = مخالفات + صيانة + عُهد + سلف + إجازات
الصافي الفعلي = max(0, الإجمالي قبل الخصم − إجمالي الخصومات)
صافي البنك = min(الصافي الفعلي, الراتب الرسمي)
الكاش = max(0, الصافي الفعلي − صافي البنك)
```

## 📈 14. ربحية العقود (Contract Profitability)

### الصيغة (من الكود):
```
تكلفة السائق = (طلبات_السائق × عمولته) + (الراتب_الفعلي × طلبات_السائق_على_العقد ÷ إجمالي_طلبات_السائق)
```

### عقد Talabat Q2 (per_order):

| البند | التفصيل | القيمة |
|------|---------|--------|
| إجمالي الطلبات | 600 (أحمد) + 300 (راجو) | 900 |
| الإيرادات | 900 × 0.900 | **810.000** |
| تكلفة أحمد | (600 × 0.250) + (150 × 600÷600) | 150 + 150 = **300.000** |
| تكلفة راجو | (300 × 0.300) + (0 × أي_نسبة) | 90 + 0 = **90.000** |
| إجمالي تكلفة السائقين | | **390.000** |
| **صافي الربح** | 810 − 390 | **+420.000** |

> ملاحظة: أحمد يعمل فقط على Talabat فنسبته 600÷600=100%. راجو per_order فراتبه الفعلي=0.
