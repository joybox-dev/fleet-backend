# ملاحظات تطوير نظام إدارة وتشغيل شركات التوصيل

يرجى مراجعة الملاحظات التالية لتطوير النسخة الحالية من النظام:

## 1. الهيكل العام والقائمة

* إعادة ترتيب الأقسام حسب الأهمية التشغيلية.
* إضافة قسم الطلبات والتشغيل.
* إضافة قسم المحاسبة.
* إضافة قسم شؤون الموظفين HR.
* إضافة CRM مصغر.
* تحسين شكل القائمة الجانبية والأيقونات.
* إضافة قسم الإعدادات والصلاحيات.

## 2. Dashboard والتحليلات

* إضافة Dashboard رئيسي للإدارة.
* إضافة Dashboard داخل كل قسم.
* تحليل يومي / شهري / ربع سنوي / سنوي.
* عرض أداء العقود، الطلبات، الإيرادات، المصاريف، الكاش، الربحية.
* مقارنة الأداء الفعلي مع التارقت.
* تنبيهات عند انخفاض الأداء أو وجود مشكلة.

## 3. العقود والمشاريع

* إضافة Dashboard خاص بالعقود.
* ترتيب العقود حسب الطلبات اليومية والشهرية.
* إضافة Target لكل عقد: يومي / شهري / ربع سنوي / سنوي.
* تحليل ربحية وتكلفة كل عقد.
* توضيح الكاش لكل عقد على حدة.
* إصلاح مشكلة إضافة عقد جديد ورسالة:
  **The fixed monthly field must be a number**
* قبول الرقم 0 والأرقام العشرية في الحقول المالية.

## 4. التشغيل والطلبات

* إضافة قسم لاستلام ومتابعة الطلبات.
* مصادر الطلبات: Keeta، جاهز، طلبات، WhatsApp، Instagram، TikTok، Snapchat، طلبات يدوية.
* تحديد طريقة الدفع: كاش أو مدفوع أونلاين.
* تحديد طريقة التوصيل: المنصة، Keeta، أو سائقين الشركة.
* متابعة حالات الطلب: جديد، جاري التوصيل، تم التسليم، ملغي، متأخر.
* ربط كل طلب بالعقد، العميل، السائق، المركبة، الكاش، والإيرادات.

## 5. السجل اليومي ورفع Excel

* إضافة إمكانية رفع ملف Excel للسجل اليومي.
* الملف يشمل: الطلبات، الكاش المعلق، الكاش المستلم، الكاش المسلّم، الفروقات.
* عرض Preview قبل الاعتماد.
* إمكانية تعديل البيانات قبل الحفظ.
* منع التكرار.
* ربط السجل اليومي بالعقد، السائق، المركبة، التاريخ، وعدد الطلبات.

## 6. تنبيهات WhatsApp للسائقين

* بعد رفع ملف Excel واعتماد البيانات، يرسل النظام تنبيهات تلقائية للسائقين عبر WhatsApp.
* تنبيه للسائق إذا عليه كاش معلق.
* تنبيه للسائق إذا عدد طلباته أقل من التارقت.
* إمكانية تخصيص الرسائل.
* حفظ سجل الرسائل المرسلة.
* دعم WhatsApp API مستقبلاً.

## 7. الموظفين والسائقين

* تحديد نوع الموظف: سائق، إداري، مشرف، مدير، محاسب، خدمة عملاء.
* فصل الموظفين الإداريين عن التشغيليين.
* السائقين يتم احتسابهم ضمن المصاريف التشغيلية.
* الموظفين الإداريين ضمن المصاريف الإدارية.
* إضافة صلاحيات حسب نوع المستخدم.
* إضافة Activity Log لمعرفة من عدل البيانات.

## 8. شؤون الموظفين HR

* ملفات كاملة للموظفين.
* العقود، الإجازات، الحضور، الرواتب، المستندات، تقييم الأداء.
* تنبيهات انتهاء الإقامة، الرخصة، العقود، التأمين.
* ربط السائق بالمشروع والعقد.

## 9. المركبات والصيانة

* إضافة ملخص داخل قسم الصيانة.
* عرض مبالغ الصيانة، أكثر السيارات دخولاً للصيانة، أكثر الأعطال تكراراً.
* تقييم الكراجات ووضع علامة على الكراج السيئ.
* تسجيل مدة الصيانة لكل سيارة.
* تنبيه إذا تأخرت السيارة داخل الكراج.
* تحليل شهري / ربع سنوي / سنوي.

## 10. استلام وتسليم السيارات

* إضافة قسم لاستلام وتسليم المركبات.
* تسجيل السيارة، السائق، التاريخ، العداد، الوقود، حالة السيارة، الملاحظات.
* طباعة نموذج استلام / تسليم سيارة.
* طباعة عقد أو عهدة تسليم للسائق.
* رفع صور السيارة وتوثيق الأضرار.

## 11. المخالفات

* تسجيل المخالفة على المركبة فقط.
* النظام يربط المخالفة تلقائياً بالسائق حسب تاريخ ووقت استخدام المركبة.
* ربط المخالفة بسجل استلام وتسليم المركبة.
* إمكانية التعديل اليدوي عند الحاجة.

## 12. الرواتب

* طباعة سند استلام راتب للموظف.
* يحتوي على الراتب، البدلات، الخصومات، صافي الراتب، التاريخ، توقيع الموظف والإدارة.
* حفظ نسخة PDF.
* تحديد حالة الراتب: تم الاستلام / لم يتم الاستلام / بانتظار التحويل.

## 13. الكاش والمحاسبة

* فصل الكاش لكل عقد.
* ربط الكاش بالسائق والعقد.
* معرفة الكاش المستلم، المسلّم، المتبقي، العجز أو الزيادة.
* إضافة Driver Wallet لكل سائق.
* إضافة محاسبة متكاملة: الإيرادات، المصاريف، الفواتير، الذمم، الصندوق.
* ربط المصاريف والإيرادات بالعقود.
* تقارير P&L و Cash Flow و Cost Centers.

## 14. CRM مصغر

* إضافة CRM بسيط لإدارة العملاء والمتابعات.
* بيانات العميل، أرقام التواصل، حالة العميل، آخر تواصل، المتابعة القادمة.
* ربط العميل بالعقود والمشاريع.
* تذكيرات متابعة.
* تصدير بيانات العملاء Excel.

## 15. الاستيراد والتصدير

* إضافة Import / Export لكل قسم.
* دعم Excel و CSV.
* تصدير التقارير PDF و Excel.
* Preview قبل الاستيراد.
* تعديل البيانات قبل الحفظ.
* Templates جاهزة لكل قسم.
* سجل عمليات الاستيراد والتصدير.

## 16. Multi Company

* عند إنشاء شركة جديدة، يمكن اختيار نوع النظام:
  * خفيف
  * متوسط
  * كبير
* إمكانية تفعيل أو تعطيل الأقسام حسب احتياج كل شركة.
* كل شركة تكون بياناتها منفصلة.
* صلاحيات وإعدادات مستقلة لكل شركة.
* تجهيز النظام للبيع مستقبلاً كـ Multi Company.

## الهدف العام

تحويل النظام إلى منصة ERP تشغيلية ومالية متكاملة لشركات التوصيل، بحيث تكون البيانات مترابطة بين الطلبات، العقود، السائقين، المركبات، الكاش، المحاسبة، والتقارير.
